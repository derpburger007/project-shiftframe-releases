# project shiftframe.

project shiftframe. is a Windows 11 companion for your Apex Legends settings, made by a player. This repository holds its releases. The source code isn't published here.

project shiftframe. is unofficial and isn't affiliated with or endorsed by Electronic Arts or Respawn Entertainment.

## What it does

- Shows at a glance whether Apex's settings files were found, your display mode, your last snapshot and whether anything changed since
- Takes snapshots of your Apex settings, keybinds and video settings, and after a patch lists every setting that changed with its old and new value
- Can take a snapshot automatically at launch whenever Apex has changed your files, if you turn that on
- Finds any setting or action with Ctrl+K
- Launches Apex through Steam and opens your config, game or snapshot folder in one click
- Daylight Aqua and Midnight Lagoon looks, glass from clear to solid, your own picture behind the glass, and Reduce motion

Restoring snapshots, stretched resolutions and FOV within the game's limits, Now Playing, per-game colour, a reticle designer and more are planned for later versions.

## Download

Download `project-shiftframe-<version>.exe` from [Releases](../../releases/latest) and run it. It's a single portable file: no installer, no admin rights. You'll need 64-bit Windows 11.

The file isn't code signed, so Windows SmartScreen and antivirus software may warn you. Only run files from this repository's Releases page. Each release lists the file's SHA-256 so you can check it.

## Privacy

- project shiftframe. has no accounts, telemetry, analytics or ads.
- Your settings and snapshots stay on your PC.
- It only reads Apex's settings files. This version never changes them.
- It doesn't inject into Apex, read its memory, send it input, or automate movement, recoil or anything else in a match.
- It never downloads or runs someone else's config files.

## Updates

There's no automatic update check yet. New versions appear on the [Releases](../../releases) page, each with notes on what changed.
